Creacion de usuario para uso de la VPN

1-Generar claves desde la aplicación, se generan automaticamente

2-Verificar la creación de la claves

cat mikecotzo_private.key
=oKiFIke7NgR3infqfLiSl0g2iKML35dsEF1gaRSvC00=

cat mikecotzo_public.key
vE6M/drp16y0SUk7RUsFZSulwr1nMuBmstwoGIgzFBU=


3- Asignar la IP interna

mikecotzo IP 10.6.0.5  (la ip se asigna segun el numero de usuario en este caso la 10.6.0.1 (servidor), 10.6.0.1 (usuario client1)

4-Agregar el peer (nodo)(equipo) al servidor

sudo nano /etc/wireguard/wg0.conf  (abrir el archivo para agregar peer)

[Peer]
PublicKey = vE6M/drp16y0SUk7RUsFZSulwr1nMuBmstwoGIgzFBU=
AllowedIPs = 10.6.0.5/32

5-Crear archivo cliente

[Interface]
PrivateKey = =oKiFIke7NgR3infqfLiSl0g2iKML35dsEF1gaRSvC00=
Address = 10.6.0.5/24
DNS = 1.1.1.1, 8.8.8.8

[Peer]
PublicKey = fZrG0x6jFTRM/wwOasP7+ww4uc1bHnKJ6Zhnx6ZB8gk=
Endpoint = 161.153.28.223:51820
AllowedIPs = 0.0.0.0/0
PersistentKeepalive = 25


en linux verificar tener la herramienta wireguard tools

sudo dnf install wireguard-tools -y

En windows instalar el programa, crear tunel vacio y agregar a la configuración la configuración del archivo cliente.
